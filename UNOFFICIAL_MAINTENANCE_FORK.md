# Independent Community Maintenance

This repository is maintained by the PastureStack community as an independent
compatibility project for legacy 1.6 deployments.

It is not affiliated with, endorsed by, sponsored by, or supported by the
historical platform vendor, SUSE, or their affiliates. Third-party names and
marks remain the property of their respective owners and are used only where
required for provenance.

The maintenance objective is to preserve required metadata and system
container behavior while replacing unsupported build or runtime dependencies
only when tests demonstrate that the change is safe. This project must not be
presented as an official vendor or SUSE release.
