## PastureStack Maintenance

PastureStack maintains this derivative as an independent community
compatibility project under the repository and product name
`hosts-file-updater`. PastureStack changes include modern build maintenance,
input validation, test coverage, documentation, and naming updates while
preserving the legacy metadata protocol required by existing deployments.

PastureStack is not affiliated with, endorsed by, sponsored by, or supported
by Rancher Labs, SUSE, or their affiliates. References to Rancher identify the
legacy compatibility target and original source only.
